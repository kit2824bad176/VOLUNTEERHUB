# 🤝 VolunteerHub

A full-stack web application for managing and tracking volunteer activities.

## ✨ Features

- 👤 User registration and login
- 🤝 Volunteer activity management
- 📋 Track volunteer participation
- 📊 Organized volunteer information
- 🔐 Secure application structure
- 🖥️ Responsive web interface

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
